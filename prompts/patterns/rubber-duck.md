# Rubber Duck Prompt

> Use this prompt when you're stuck and need to think through a problem out loud.
> Explain the problem to Copilot as if explaining to a rubber duck — it will ask clarifying questions and help you reason through to a solution.

---

I'm going to explain a problem I'm working on. Please listen carefully, ask clarifying questions if anything is ambiguous, and help me reason through it step by step.

Here's the problem:

<describe the problem in your own words — what you expected to happen, what is actually happening, and what you've already tried>

---

## Copilot instructions

1. Let the user explain fully before suggesting solutions.
2. Ask one clarifying question at a time if the problem is unclear.
3. Summarize your understanding of the problem back to the user before proposing a solution.
4. Propose solutions in order of simplicity — start with the most straightforward approach.
5. If the user has a hypothesis, help them test it rather than immediately offering an alternative.
