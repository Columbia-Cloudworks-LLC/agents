# Test Generation Prompt

> Copy this prompt into Copilot Chat or use `#prompt:test-generation-task` if saved in `.github/prompts/`.

---

Please generate comprehensive tests for the following code.

**Provide context:**
- File: `#file:<path>` or paste the function/class below
- Testing framework in use: <framework, e.g. Jest, pytest, xUnit>
- Any existing test files: `#file:<test-file-path>`

---

## Instructions

1. Use the **same testing framework** already in the project.
2. Follow the **Arrange → Act → Assert** pattern.
3. Generate tests for:
   - Happy path (normal usage)
   - Boundary values (empty, null, zero, max)
   - Error paths (invalid input, exceptions)
   - Side effects (writes, events, calls to dependencies)
4. Name each test clearly: `"should <behavior> when <condition>"`
5. Mock all external dependencies (DB, HTTP, file system).
6. Add a comment at the top: `// Generated by GitHub Copilot — review before committing.`

---

Return the complete test file, ready to save.
